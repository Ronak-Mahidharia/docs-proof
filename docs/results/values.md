# Changed values: a wide search, then a local model

Generated by `scripts/run_model.py`. Don't edit by hand.

A changed value is a new default for an option (a number in the code) or a higher minimum Python version. The search, with no AI, finds every doc line about the setting that shows the old value. A local model then reads each of those lines with the lines around it and says whether it states the old value as the project's own setting. Each finding must quote the doc line and the code line, and a finding whose quotes aren't really there is dropped. The models run through Ollama on this computer, at temperature 0 with a fixed seed.

The prompts: v1 asks whether the line states the old value "as true now". v2 adds a list of lines that only look like the value (another program, a log, a requirement marker, a past release). v3 asks what the line says, whether or not it's still true. v4 has the model first say what the line is about, from a fixed list, and which value it states.

Chosen by the rule fixed before test was run (the highest F1; then fewer false alarms; then the smaller model; then the earlier prompt): **qwen3:8b, v1**.
